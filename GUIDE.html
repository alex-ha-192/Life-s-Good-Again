Your rooted LG: Tiles Home on the Home button, and LG's tracking switched off.

Kit for rooted TVs, 25 Nov 2026. Built for a 2023 LG 43" 4K on webOS. One run from any laptop sets it all up. After that the TV looks after itself, so nothing has to stay on. The blocking is done by Life's Good Without Spying, an existing Homebrew Channel app. This kit installs and configures it, then adds what it doesn't cover.

Who does what new

Life's Good Without Spying (LGWS) is a free, MIT-licensed Homebrew Channel app by lewisdoesstuff. Its author tested it on webOS 23, the same generation as a 2023 LG. Rather than duplicate it, the kit uses it for the blocking and keeps only what it doesn't do.

The installer checks whether LGWS is installed. If it isn't, setup.py downloads LGWS's latest release on your computer, so the TV doesn't need to reach GitHub. It checks the file against the SHA-256 in LGWS's own release manifest and sends it over with the kit, and the TV checks it again before installing. You can also install it yourself first, from Homebrew Channel. Then the installer sets LGWS's options to match yours and switches its protection on. You can open the LGWS app afterwards to look or change things. The kit's extras stay in place.

1. Root the TV pointer only

This guide doesn't walk through rooting. Whether a TV can be rooted depends on its exact firmware, and the methods change as LG patches them. The webOS Homebrew community keeps the current answer. Check your model and firmware at cani.rootmy.tv and follow their instructions there. Firmware can't be downgraded, so check before you let the TV update.

You're ready when the Homebrew Channel app shows root. Then, in Homebrew Channel's settings, turn on SSH Server.

Homebrew Channel's SSH logs in as root, and the password starts as alpine. Change it the first time you log in, with passwd, or set up an SSH key.

2. Install, once, from any laptop

You need Python 3.8 or newer and the kit folder. There's nothing else to install. Put the laptop on the same network as the TV and turn the TV on.

python3 setup.py --root --skip dns,router --dry-run     # see the plan, change nothing
python3 setup.py --root --skip dns,router               # do it (finds the TV; or add --tv 192.168.1.50)

  1. Pair

    Accept the prompt that appears on the TV. This is the same pairing LG's phone app uses.

  2. Privacy settings

    It backs up your current settings, then turns off Live Plus (ACR), home promotions, the promo video, sports alerts, recommendations and Home Auto Launch.

  3. On-screen switches

    It opens the right Settings pages and tells you what to untick. See step 3.

  4. Tiles Home

    It takes a snapshot of your installed apps and icons and builds Tiles Home with them.

  5. On the TV

    It copies the kit to the TV over SSH, where ssh asks for the root password, and runs the installer there. The installer installs and switches on Life's Good Without Spying, then adds the kit's extra names and the firewall. It also starts the agent that handles the Home button, power-on and the settings guard. A boot hook brings all of it back after every restart. LGWS can take a minute or two to apply.

If the root step stops with "Life's Good Without Spying isn't on the TV", nothing on the TV has been changed. On the TV, open Homebrew Channel and install Life's Good Without Spying, then run the same command again. Or add --no-lgws to use the kit's own blocklist instead. The line above that message says why it failed: no route to GitHub, a certificate problem on the TV, or a damaged copy.
When it finishes, press Home on the remote: Tiles Home should open. A summary is saved to ~/.config/lgtv-privacy/setup-report.html. You can put the laptop away now.

3. The switches only the remote can change

LG keeps the legal consents off-limits to apps, so these are done by hand once. Setup opens the pages for you. Menu names are for webOS 23 and vary slightly by region.

WhereWhat to do
Support, Privacy & Terms, User AgreementsUntick Viewing Information, Voice Information, Interest-Based Advertising, Content Recommendation and Live Plus. Keep only Terms of Use if you want the Content Store.
General, System, Additional Settings, AdvertisementTurn on Limit Ad Tracking and turn off Personalised Advertising. Use Reset Advertising ID once.
General, AI ServiceTurn off AI Recommendation, Smart Tips, voice data collection and any always-listening option.
General, Devices, TV ManagementTurn off device-info sharing you don't use.

LG can re-tick a consent after an update. The guard can't see these ones, so look again after a firmware update.

Options

Add these to the setup command, or run it again with them later.

OptionDoes
--keep-storeUse this if you install or update apps from LG's Content Store. By default LGWS blocks LG's service platform (SDP) 60 seconds after boot, once the TV has set its clock. That's the LGWS default, and it stops the Content Store opening.
--keep-voiceKeeps LG's voice services. By default LGWS stops them, so the mic button on the remote stops working. It doesn't turn off the microphone hardware.
--root-tiers base,strict,dohThe most blocking. It adds the kit's strict names and turns on LGWS's Content Store, Home sessions, ThinQ and LG Channels categories. It also stops app updates, LG account, Search and some Home previews. The default is base,doh.
--block-updatesBlocks LG firmware and app updates, through LGWS's updates category, so an update can't take root away. You also miss LG's security fixes. Homebrew Channel has its own firmware switch too.
--no-lgwsLeave LGWS out. The kit puts its own whole list in /etc/hosts instead, and no services are stopped.
--home-code NYour remote's Home key code, so the Home button is caught the instant you press it, not when LG's Home appears. Without it you may see LG's Home for a moment. To find it, SSH into the TV, run node /var/lib/webosbrew/lgkit/find-home-key.js, and press Home.
--root-key ~/.ssh/keyLog in with an SSH key instead of the password.
--tv 192.168.1.50Use this address instead of searching the network.

No laptop to hand? From a phone

Install Life's Good Without Spying from Homebrew Channel first, so the TV doesn't need to download it. This installs the on-TV part only: LGWS settings, extras, firewall, Home button and guard. The guard switches the privacy settings off within a minute anyway. Any SSH app works, for example Termux on Android. Copy dist/lgkit-root.tar.gz from the kit to the phone, then:

scp lgkit-root.tar.gz root@192.168.1.50:/tmp/
ssh root@192.168.1.50
mkdir -p /tmp/kit && tar -xzf /tmp/lgkit-root.tar.gz -C /tmp/kit && sh /tmp/kit/root/install.sh

install.sh --help lists the same options: --keep-store, --keep-voice, --tiers, --block-updates, --home-code, --no-lgws. Tiles Home from the bundle shows apps from the TV's live list. Running setup from a laptop also bakes in your app icons.

Using Tiles Home

Five pages sit in a ring: favourites, apps, inputs, media, settings. The page you're on sits in the middle, with the next ones on each side. There's a clock in the corner, and it makes no network calls.

RemoteIn Tiles Home
← →Turn the ring to the previous or next page. It wraps: right from settings brings back favourites. The two pages on each side stay in view, smaller and faded.
↑ ↓Move through the list on the page in the middle. Each page remembers where you were.
OKOpen the app, input or setting.
YellowAdd to favourites, or take it out. It stays on its own page with a small star. On the favourites page, yellow removes it from favourites only.
RedOn favourites: pick up the selected item, move it with ↑ ↓, then press OK or red to drop it.
BackJump back to favourites, or cancel a move.
PointerClick a side page to turn to it; click a row once to select it and again to open it.

LG's own Home is under Settings, LG Home. Opening it from there leaves it open. The Home button always comes back to Tiles Home.

Check, change, undo

python3 setup.py status                               # from the laptop
python3 setup.py undo                                 # remove it all and restore your settings backup
# or on the TV, over SSH:
sh /var/lib/webosbrew/lgkit/install.sh --status       # LGWS, extras, firewall, agent, last guard run
node /var/lib/webosbrew/lgkit/lgkit-agent.js --guard  # re-check the settings now
sh /var/lib/webosbrew/lgkit/install.sh --uninstall    # all of it off

To change an option, run setup or install.sh again with the new flags. Logs are in /var/lib/webosbrew/lgkit/ (boot.log, agent.log). Uninstalling takes the kit's extras out and switches LGWS's protection off if the kit switched it on. If LGWS was already on before, it's left on. The Tiles Home and LGWS apps stay installed. To remove LGWS completely, press Disable protection in its app first, then uninstall it from Homebrew Channel. Its own README explains why the order matters.

What's blocked, and what that breaks

SettingBlocks or stopsBreaks
DefaultLGWS: LG's ad network, ACR (Live Plus, Alphonso), telemetry and LG's dashboard hosts. It stops the ad, ACR, telemetry and voice services and blocks SDP after 60 seconds. Kit: per-country ad servers and the DoH services.The Content Store (use --keep-store), the remote's mic button (use --keep-voice), LG Channels rows and sports cards on LG's Home.
strictAlso: LG's store and recommendation hosts, Home sessions (wiselg), ThinQ and assistant daemons, LG Channels, and the kit's strict names (lgtvsdp, lgappstv, lgtvcommon, lge.com)App updates, LG account, Search, Home previews and channel metadata
--block-updatesLG's firmware and app update serversUpdates and their security fixes, and app installs

Streaming apps (Netflix, YouTube, Prime, Disney+, Plex, Jellyfin) use their own domains and keep working. AirPlay keeps working too. All of this only affects the TV. Other devices on your network aren't touched.

What is DoH? DNS-over-HTTPS. Normally the TV looks up a name like lgsmartad.com in plain text, through the system resolver, which reads the hosts file and blocks it. With DoH, an app sends the lookup encrypted, as ordinary web traffic, straight to a service like Google or Cloudflare. It never touches the hosts file. The kit blocks those services by name and the firewall blocks their addresses. LGWS's README notes this same limit of a hosts list.

Risks, plainly

  • Rooting is the risky part, and it's outside this kit. LG can refuse warranty service for software damage caused by it.
  • LGWS goes further than the kit did on its own. It stops system services and covers them with stand-ins. It doesn't delete anything, and a reboot or its Disable button brings them back. Stopping services can upset something on a firmware its author hasn't tested.
  • This kit doesn't patch or delete anything in the system. It adds lines after LGWS's hosts block, adds firewall rules, and runs one small background app.
  • Boot safety: if the TV ever hangs during boot, Homebrew Channel's failsafe skips all boot scripts next time. The kit's hook finishes in about a second and starts everything else in the background, to stay clear of that.
  • Updates: blocking them keeps root and also leaves known bugs unfixed. If you block them, keep the TV off networks you don't trust.

What it doesn't do

  • Neither it nor LGWS deletes LG's system services. Removing those can break the TV, and updates bring them back.
  • It can't stop a connection to a hard-coded IP address that isn't on the firewall list. No public report says LG does this for ads or ACR.
  • It doesn't change the on-screen consents for you. LG only allows those with the remote.

Not yet tested on a real TV, and what I couldn't check

  • Life's Good Without Spying is third-party. I read its README, its control script and its list format, and checked the setting names and paths the kit uses against its source (version 0.12.3, last changed 23 Nov 2026). I haven't audited all of its roughly 2,700 lines of shell, and I haven't run it. Its README says most of its code was written by AI and tested on the author's own TVs: webOS 23 (LG G4), webOS 25 and webOS 4.4. The kit checks the download against the SHA-256 in LGWS's own release manifest. That catches a corrupted download, but it can't vouch for the code itself.
  • The kit's use of LGWS was tested against a stand-in that behaves like LGWS's control script: settings, enable, apply, status and disable. Covered: extras added after its block, extras kept when it re-applies, and uninstall switching it off only if the kit had switched it on. Downloading the real LGWS release on the computer was tested, with its SHA-256 matching its manifest, and so was installing that copy through the stand-in. If both that and the TV's own download fail, the installer stops before changing anything and says why.
  • LGWS's DNS filter (off by default) redirects the TV's own DNS through a local helper. The kit leaves it off. If you turn it on, the kit's firewall still lets through whichever DNS server is in the TV's resolver settings, but I haven't tested the two together.
  • The kit's own on-TV part (agent, boot hook, firewall, uninstall) was run end to end on a stand-in TV, with a fake luna-send and fake remote key events. The hosts mounts and iptables were real, in an isolated container. The likeliest differences on your TV are LG Home's app id on your firmware (the agent watches the common ones), whether iptables is there (if not, it skips the firewall and says so), and whether the install service accepts the Tiles Home .ipk. If it doesn't, install the .ipk from Homebrew Channel. install.sh --status shows each of these.
  • Found on a real 2023 TV (43UR81006LJ): its luna-send prints replies only to a terminal, so the agent and installer now go through script when they get no reply, the same workaround LGWS uses. App installs are confirmed from the installed files, not from that output. Its ip6tables has no REJECT target, so IPv6 rules fall back to DROP. The installer ends with a list of what worked and what didn't, and exits with an error if anything failed.
  • Settings: the keys come from community notes and vary by firmware. Any your TV doesn't report are skipped.
